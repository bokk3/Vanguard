[ THE CONNECTED WEB PORTAL ECOSYSTEM ]

HOW THIS PORTAL EVOLVES WITH VANGUARD

More than a static brochure. The Project Vanguard web portal is engineered to evolve into a living tactical hub interacting directly with flight saves, telemetry, and Cloudflare edge services.

PHASE I // TELEMETRY CLIENT-SIDE JSON

Black Box Sortie Replay

Drag-and-drop your local vanguard_savegame.json directly onto the web portal. The browser parses telemetry to render 3D flight trajectories, weapon hit-rate breakdowns, and exports high-res pilot scorecard badges with your Rank (S/A/B) for Discord and social sharing.

PHASE II // WEB EMBED GODOT 4 WASM

Instant Browser Hangar & Trial

Leveraging Godot 4.7's WebAssembly export, visitors can launch the 3D Hangar Turntable directly in-browser. Inspect the sculpted V-hull, customize Solar Amber vs Crimson Aggressor liveries, and fly a 90-second training sortie without installing anything.

PHASE III // CLOUDFLARE EDGE WORKERS + D1 DB

Global Ace Leaderboard & Ghosts

Cloudflare Workers and D1 database host a lightweight global leaderboard. Godot reports authenticated sortie times and PvP win streaks via HTTPRequest. Pilots can download top-ranked flight ghost trajectories to race against rival flight paths in-game.

// DYNAMIC CONTENT SYNC //
AWACS Daily Operation Feed

Cloudflare Pages Functions serve dynamic mission modifiers (/api/daily_sortie.json). On boot, the game pulls daily weather variations, high-density minefields, and tactical bounties generated by the web community.
